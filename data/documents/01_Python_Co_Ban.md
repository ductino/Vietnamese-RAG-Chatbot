# Python cơ bản

## 1. Python là gì?
Python là ngôn ngữ lập trình bậc cao, cú pháp dễ đọc và được sử dụng rộng rãi trong phát triển phần mềm, phân tích dữ liệu, tự động hóa và trí tuệ nhân tạo. Python sử dụng kiểu dữ liệu động và hỗ trợ nhiều phong cách lập trình.

## 2. Biến và kiểu dữ liệu
Biến dùng để tham chiếu tới dữ liệu. Các kiểu thường gặp gồm int, float, str, bool, list, tuple, set và dict. Python cho phép gán biến trực tiếp mà không cần khai báo kiểu trước.

## 3. Cấu trúc điều khiển
Câu lệnh if, elif và else được dùng để rẽ nhánh. Vòng lặp for thường được dùng để duyệt qua một iterable, trong khi while lặp khi điều kiện còn đúng. break kết thúc vòng lặp và continue bỏ qua phần còn lại của lần lặp hiện tại.

## 4. Hàm
Hàm được định nghĩa bằng từ khóa def. Hàm giúp chia chương trình thành các thành phần nhỏ, dễ kiểm thử và tái sử dụng. Tham số có thể có giá trị mặc định và hàm có thể trả về kết quả bằng return.

## 5. Xử lý ngoại lệ
try, except, else và finally được sử dụng để xử lý các lỗi có thể xảy ra trong lúc chương trình chạy. Việc xử lý ngoại lệ giúp ứng dụng không bị dừng đột ngột khi gặp dữ liệu không hợp lệ.

## 6. Lập trình hướng đối tượng
Python hỗ trợ class, object, inheritance, encapsulation và polymorphism. Một class mô tả thuộc tính và hành vi chung của một nhóm đối tượng.

## 7. Python trong AI
Python có hệ sinh thái mạnh cho AI và dữ liệu. NumPy hỗ trợ tính toán mảng, Pandas hỗ trợ xử lý dữ liệu dạng bảng, Scikit-learn cung cấp nhiều thuật toán machine learning và PyTorch hỗ trợ deep learning.
