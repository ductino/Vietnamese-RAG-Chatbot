# Git và GitHub

## 1. Git là gì?
Git là hệ thống quản lý phiên bản phân tán. Git giúp theo dõi thay đổi của mã nguồn, tạo branch và khôi phục lịch sử khi cần.

## 2. Repository
Repository chứa mã nguồn và lịch sử commit. Repository có thể tồn tại local trên máy tính và remote trên nền tảng lưu trữ mã nguồn.

## 3. Commit
Commit ghi lại một trạng thái thay đổi của project. Một commit tốt nên mô tả rõ thay đổi đã thực hiện.

## 4. Branch
Branch cho phép phát triển tính năng độc lập với nhánh chính. Sau khi hoàn thành, thay đổi có thể được merge vào branch chính.

## 5. GitHub
GitHub là nền tảng cộng tác dựa trên Git. Người dùng có thể lưu repository, review code thông qua pull request, quản lý issue và tự động hóa workflow.

## 6. Quy trình cơ bản
Một quy trình phổ biến là clone repository, tạo branch, chỉnh sửa code, git add, git commit, git push và tạo pull request.

## 7. Git trong dự án AI
Trong dự án machine learning, nên quản lý source code, configuration và documentation bằng Git. Dataset lớn và model checkpoint có thể cần chiến lược lưu trữ riêng thay vì commit trực tiếp vào repository.
