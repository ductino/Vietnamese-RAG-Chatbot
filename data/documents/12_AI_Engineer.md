# AI Engineer

## 1. AI Engineer là gì?
AI Engineer là kỹ sư xây dựng và tích hợp các hệ thống sử dụng machine learning, deep learning hoặc LLM vào ứng dụng thực tế. Công việc thường nằm giữa software engineering và AI.

## 2. Kiến thức cần có
Một AI Engineer nên có nền tảng Python, Git, API, SQL, machine learning và kiến thức cơ bản về deep learning. Với hệ thống LLM, cần hiểu prompt, embeddings, RAG, evaluation và model inference.

## 3. Quy trình xây dựng hệ thống
Quy trình có thể bắt đầu từ xác định bài toán, chuẩn bị dữ liệu, chọn mô hình, xây dựng pipeline, đánh giá, đóng gói API và triển khai.

## 4. AI Engineer và Data Scientist
Data Scientist thường tập trung mạnh vào phân tích dữ liệu, thống kê và xây dựng mô hình để giải quyết bài toán dự đoán. AI Engineer chú trọng nhiều hơn đến việc tích hợp mô hình vào sản phẩm và vận hành hệ thống.

## 5. AI Engineer và Backend Engineer
Backend Engineer tập trung xây dựng API, database và logic server. AI Engineer cũng cần những kỹ năng này nhưng thường bổ sung thêm pipeline inference, model serving, embeddings hoặc retrieval.

## 6. Project phù hợp
Một project RAG chatbot có thể thể hiện nhiều kỹ năng: document ingestion, chunking, embedding, vector search, LLM integration, FastAPI và giao diện chat.

## 7. Đánh giá hệ thống
Một AI application không chỉ cần mô hình tốt. Cần quan tâm latency, chi phí, độ chính xác, khả năng xử lý lỗi, logging, security và trải nghiệm người dùng.
