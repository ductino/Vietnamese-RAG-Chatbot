# SQL và xử lý dữ liệu

## 1. SQL là gì?
SQL là ngôn ngữ dùng để truy vấn và quản lý dữ liệu trong hệ quản trị cơ sở dữ liệu quan hệ. Các thao tác phổ biến gồm SELECT, INSERT, UPDATE và DELETE.

## 2. SELECT
SELECT được dùng để lấy dữ liệu. WHERE lọc bản ghi theo điều kiện, ORDER BY sắp xếp kết quả và LIMIT giới hạn số lượng bản ghi tùy hệ quản trị.

## 3. JOIN
JOIN kết hợp dữ liệu từ nhiều bảng dựa trên cột liên quan. INNER JOIN chỉ lấy các bản ghi có quan hệ ở hai phía, còn LEFT JOIN giữ toàn bộ bản ghi từ bảng bên trái.

## 4. GROUP BY
GROUP BY gom dữ liệu thành nhóm để sử dụng với các hàm tổng hợp như COUNT, SUM, AVG, MIN và MAX.

## 5. SQL trong AI
Trong project AI, SQL thường được dùng để lấy dữ liệu huấn luyện, kiểm tra dữ liệu và xây dựng feature. Với RAG, metadata của tài liệu cũng có thể được lưu trong database quan hệ.

## 6. Data pipeline
Một pipeline dữ liệu có thể gồm extraction, cleaning, transformation và loading. Chất lượng dữ liệu ảnh hưởng trực tiếp đến chất lượng của mô hình và hệ thống AI.
